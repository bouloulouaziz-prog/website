README - Hoe groot is Hogeschool Rotterdam, en wat betekent dat voor de kantines?
================================================================================

DOELGROEP
Studenten van Hogeschool Rotterdam (en de kantine als belanghebbende).

DOEL
De website maakt openbare cijfers van Hogeschool Rotterdam begrijpelijk en
beantwoordt de vraag: "Hoe groot is Hogeschool Rotterdam en wat betekent dat
voor de kantines?" Verder geeft de site een aanbeveling voor de kantine.

HOE OPEN JE DE SITE?
1. Pak de map uit (als het een zip-bestand is).
2. Dubbelklik op index.html. De site opent in je browser.
3. Je hebt geen internet en geen server nodig. Alleen de externe bronlinks
   (naar de pdf's en webpagina's) openen niet zonder internet.
Je mag de hele map kopieren naar een andere plek of computer. Alles blijft werken,
omdat alle paden relatief zijn.
